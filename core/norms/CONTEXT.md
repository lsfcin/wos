# norms
> Rules obeyed rather than enforced. One file each; `AGENTS.md`'s rule block is generated from them.

The INDUCED half of the line whose ENFORCED half is `file_law.py` / `schema_law.py` /
`feature_law.py` ([`../SCHEMA.md`](../SCHEMA.md) § Vocabulary). A norm that acquires a checker stops
being a norm and becomes a hook.

**Every file here is paid by every session.** `AGENTS.md` is always loaded, so a norm's body is its
whole cost and its whole benefit — write the rule, not the argument for it. The rationale belongs in
the `SPECS.md` that owns the rule, and the norm points at it.

**Order is the registry's, not this directory's.** The generator publishes group `norms` in the order
[`../features.txt`](../features.txt) lists it, because a second ordered list is the asymmetry this
workspace keeps paying for. Moving a rule up the prompt means moving its registry row.

Generated by [`../hooks/routing/norms.py`](../hooks/routing/norms.py), which is also the group's one
feature-switch: a norm switched off is not written into `AGENTS.md`, so the ablation removes it from
every session's prompt rather than merely marking it inactive.
